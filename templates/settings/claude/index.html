Claude Desktop

Connect Claude Desktop on your computer to your Kosmos notes. Claude can then list, search, and read the Library and the notes of any matter you have access to. Access is read-only (Claude Desktop never writes notes) and personal: it uses your token below, and sees exactly what you can see.

Setup

  1. Install uv if you don't have it (it runs the connector script with no other setup).
  2. Download kosmos_notes_mcp.py and save it somewhere permanent (for example your home folder).
  3. In Claude Desktop, open Settings, then Developer, then Edit Config. This opens claude_desktop_config.json. Paste the block below, replacing /path/to/kosmos_notes_mcp.py with where you saved the script.
  4. Restart Claude Desktop. The kosmos tools appear under the tools icon in the chat input.
