LibreOffice Companion

The companion extension connects your local LibreOffice Writer to a drafting session. Edits you approve in the drafting window appear in the open document as tracked changes, and the AI reads the document as you have it (your hand edits included). No more downloading and syncing between rounds.

Download kosmos-companion.oxt

  1. Install the downloaded file in LibreOffice: Tools, Extension Manager, Add (or double-click the file). Then restart LibreOffice. On Ubuntu or Debian, if the install fails with an error, run sudo apt-get install libreoffice-script-provider-python python3-uno and try again.
  2. Open the draft ODT from the matter's Drive folder on your computer, and start a drafting session for the same file here in Kosmos.
  3. In Writer, choose Kosmos, then Connect to drafting session. The document pairs with the session by filename.

The download is personal: it carries your server address and access token, so it works with no configuration. Do not share the file. Each user should download their own copy from this dialog.
