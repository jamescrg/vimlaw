{% load ai_extras %} {% comment %} The persistent status line: one quiet row floating above the composer. Matter and model live in the header badges, so this carries only the numbers: citation state on the left; on the right the estimated cost (last exchange and conversation total), token totals, and, while an agentic turn works, the live run strip with cancel. Transient activity never appears here; it lives at the tail of the transcript. One template plays both roles: oob=False renders the standing container (conversation-standalone.html), oob=True is the fragment the views append to htmx responses (views._statusbar_html; case chats only, other surfaces have no target). The container and fragment must carry identical class/hx-ext attributes: a morph syncs attributes, and dropping hx-ext="morph" from the live element would silently downgrade every later out-of-band swap to innerHTML. {% endcomment %}
