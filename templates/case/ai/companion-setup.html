LibreOffice Companion

The companion extension connects your local LibreOffice Writer to Kosmos. With a draft linked to a conversation and the same document open in Writer, edits you approve in chat appear in the document as tracked changes, and the AI reads the document as you have it (your hand edits included).

Download kosmos-companion.oxt

  1. Install the downloaded file in LibreOffice: Tools, Extension Manager, Add (or double-click the file). Then restart LibreOffice. On Ubuntu or Debian, if the install fails with an error, run sudo apt-get install libreoffice-script-provider-python python3-uno and try again.
  2. Link a draft to an AI conversation (the paperclip button in the chat header), and open the same ODT from the matter's Drive folder on your computer.
  3. In Writer, choose Kosmos, then Connect to drafting session. The document pairs with its link by filename.

The download is personal: it carries your server address and access token, so it works with no configuration. Do not share the file. Each user should download their own copy from this dialog.
