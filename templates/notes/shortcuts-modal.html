Keyboard Shortcuts

{% comment %} Palette order: Alt+`/1-6 mirror the highlight menu's chips left to right; the letters are mnemonic aliases. {% endcomment %}
Text Formatting
Ctrl + B Bold
Ctrl + I Italic
Ctrl + Shift + S Strikethrough
Ctrl + E Inline code
Highlights
Alt + ` or Alt + C Remove highlight
Alt + 1 or Alt + A Gray highlight
Alt + 2 or Alt + Y Yellow highlight
Alt + 3 or Alt + G Green highlight
Alt + 4 or Alt + R Red highlight
Alt + 5 or Alt + P Purple highlight
Alt + 6 or Alt + O Orange highlight
Headings
Ctrl + 1 - 5 Heading 1-5
F2 / F3 / F4 Heading 2 / 3 / 4
Ctrl + 0 Normal paragraph
Lists & Blocks
F7 or Ctrl + 7 Bullet list
Ctrl + 8 Blockquote
Ctrl + Alt + C Code block
Tab / Shift + Tab Indent / outdent in code block
Ctrl + ↑ / ↓ Move list item up/down
Ctrl + D Delete block
Ctrl + ; or Ctrl + Shift + ; Insert source (use the shifted chord on Linux, where Ctrl+; opens the system emoji picker)
General
Ctrl + H Search & Replace
Ctrl + S Save
Ctrl + Z Undo
Ctrl + Shift + Z Redo
Ctrl + ? Show shortcuts
